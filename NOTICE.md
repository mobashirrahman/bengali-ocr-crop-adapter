# Modification notice

This repository distributes a Bengali OCR LoRA adapter fine-tuned from [Datalab Surya OCR 2](https://huggingface.co/datalab-to/surya-ocr-2). The adapter weights are modified model files; the upstream base model remains separate and is not included. This project is independent and is not endorsed by Datalab.
